# 个人 AI 档案

> li 的个人 AI 档案库：A 股交易框架、每日复盘规则与自研工具。由 Muse（B max）维护，定期同步。
> 最后更新：2026-11-28

## 我是谁

- A 股交易者，超短选手，目标是捕捉主升浪启动
- 偏好龙头股、阶段性妖股、热门题材和趋势股
- 决策顺序固定：市场环境 → 板块主线 → 个股 → 量价结构与买卖点
- 均线标准：MA5 / MA20 / MA100（日线）
- 交易纪律：先看市场、再看板块、再选个股；不只凭放量买入；无主线、无确定性结构时，空仓也是决策

## 交易框架（破甲版，十步）

1. 大盘环境 2. 板块环境 3. 个股地位 4. 均线结构 5. 成交量
6. 承接情况 7. 买点 8. 风险 9. 预期收益 10. 最终决策

每次分析须给：看多依据、看空依据、最关键的验证条件、交易逻辑失效的条件、可能出现的错误判断。

买点（四种）：A. 分歧转一致 B. 缩量回调 C. 放量突破 D. 龙头分歧低吸

不直接当买点：单纯超跌、单纯放量、单纯缩量、只站上 5 日线但 5 日线仍向下、下跌趋势中的一次反弹。

## 仓位与总原则（2026-11-23 改定）

- 只做确定性，不确定的不做，宁可空仓等待
- 仓位只有满仓或空仓，不留半仓；实盘与 AI 演示统一此规则（此前每次 1/3 仓、最多同时持有 3 只的规则已废止）
- 复盘说空仓就不买；只买每天筛选出的符合条件的票

## 大盘环境与情绪应对（2026-11-23）

- 大盘环境应对策略：100 分制五项评分（指数趋势 / 成交量能 / 市场广度 / 短线情绪 / 赚钱效应），MA100 为趋势参考；80+ 主升、65–79 强势震荡、50–64 缩量轮动、35–49 弱势退潮、0–34 恐慌空仓；评分未回测，只作战法参考
- 情绪应对策略：按高潮 / 分歧 / 退潮 / 冰点 / 修复给战法，含情绪周期否决检查；交易建议与筛选须与应对策略一致；恐慌 / 退潮空仓时筛选照常做、仅观察不买入（2026-11-27 改定：去掉「大盘环境允许做多」一项，其余性价比条件不变，筛出的票标明仅观察、不买入；买入纪律不变，复盘说空仓就不买）
- 成交量变化结合情绪周期七阶段（冰点 / 修复 / 启动 / 加速 / 分歧 / 退潮 / 出清）判断

## AI 演练新规则（2026-11-26 定稿，三连阳公式，取代旧六条与博弈论模式）

- 买入前提：20 日线趋势向上（20 日均价线 5 日变化率 >+1%）＋三连阳＋高点逐日抬高
- 买点：股价接近五日线时全仓买入；卖点：连续三天最低价越来越低且三天收阴时全仓卖出
- 仓位：满仓 / 空仓；无固定止损

## 通达信选股公式（2026-11-26，形态条件、不是买入信号）

- 20 日线向上三连阳高点抬高；最近 20 个交易日有两连板（涨停 = 收盘价 ≥ 前收 ×1.095 且收盘价为当日最高价，20cm 板改 1.195，ST 股不适用）
- Python 复刻：quant/tdx_formula.py，数据源同花顺 Financial-API 前复权日 K

## 每日复盘（十二项，交易日收盘后）

大盘情绪、涨跌停家数、成交量变化、最近强势板块、主线题材、题材内龙头/中军/跟风/补涨、题材内高度/宽度、交易建议、空仓提示、每日涨停复盘、每日龙虎榜复盘、每日最强板块概念。

午盘盘点：工作日 11:40，按收盘结构写 11:30 午盘数据，不做筛选。

选股框架（2026-11-26）：复盘 → 板块 → 选股 → DSA 打分 → 用户决策；16:00 批量调 DSA 打分，DSA 减仓/看空剔除，其余按评分排序呈决策清单。

收盘复盘融合自 2026-11-26 起为 Muse＋Gemini＋Groq＋GLM-5.3 四方；GPT 因账号额度用完缺席。

跟踪股删除后 1-2 日复看：删除后 1-2 个交易日内每天收盘核查，收盘收回 MA5 且期间不创新低（缩量为佳）即重新入池，2 日内未收回则彻底移出。

## 每日筛选

- 范围：当日涨停池 + 当日强势板块，优先最强概念，兼顾次强概念和有持续性的题材
- 性价比规则：趋势完好、回踩支撑有效、分歧后承接、5 日线拐头向上、位置合理（未远离 5 日线、未连续加速）、上方有空间
- 中军 / 趋势核心与题材正宗的补涨，优先于高位龙头追涨；排除连续加速、高位放量滞涨、远离 5 日线的纯追高
- 最多 5 只，宁缺毋滥；没有符合条件的就明确说没有
- 实盘只买每天筛选出的票，满仓 / 空仓；复盘说空仓不买
